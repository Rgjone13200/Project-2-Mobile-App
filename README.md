# ShopEasy Flutter App

## Project Description

ShopEasy is a grocery shopping application created using Flutter and Dart in Visual Studio Code. This project demonstrates interactive features, images, animations, and modern app design.

## Features

- Browse grocery products with images and prices.
- Search for grocery items.
- Filter products using a price slider.
- Add products to a shopping cart.
- View the shopping cart total.
- Switch between light and dark mode.
- Navigate using a menu.
- Smooth animations and scrolling effects.

## Technologies Used

- Flutter
- Dart
- Visual Studio Code
- Material Design 3

## How to Run the App

1. Download or clone the project from GitHub.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Run the following commands:

```bash
flutter pub get
flutter run -d chrome
```
